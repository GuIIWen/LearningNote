# Prompt Chaining (提示词链) - 智能 Agent 设计模式

## 1. 核心定义与哲学
### 核心理念
- **分而治之 (Divide-and-Conquer)**：将单一、复杂的 Monolithic 任务拆解为一系列原子化的子任务。
- **序列化执行**：通过多个 LLM 调用序列替代单次调用，降低模型的认知负荷。
### 运行机制
- **数据流转**：前一个步骤的输出 (Output) 充当下一个步骤的输入 (Input/Context)。
- **算法驱动**：在链条节点间嵌入特定的处理算法 (Algorithms)，确保数据清洗与逻辑一致性。

## 2. 关键架构组件
### 任务分解 (Decomposition)
- 识别复杂流程中的关键节点（如：语义消歧 -> 实体提取 -> 逻辑推理）。
### 状态管理 (State Management)
- 维护链条执行过程中的中间变量。
- **记忆系统集成**：挂载长期与短期记忆，防止长上下文丢失。
### 工具与协议 (Integration)
- **MCP 协议**：与外部数据源和本地工具进行标准通信。
- **API 调用**：在特定节点触发外部系统交互。

## 3. 核心优势分析
### 可靠性与精度
- **减少幻觉**：更聚焦的 Prompt 使得 LLM 输出更符合预期。
- **准确性提升**：每一步都可以进行验证 (Verification)，确保逻辑不偏离。
### 开发与运维
- **模块化调试**：可针对单一节点进行 Prompt 优化，无需重构全局。
- **可观测性**：清晰追踪数据在链条中的流转路径。
### 性能优化
- 针对不同复杂度的节点选择不同参数规模的模型（如：简单节点用小模型，逻辑节点用大模型）。

## 4. 工业级应用场景 (以航空制造为例)
### 本体建模 (Ontology Modeling)
- **第一步**：长技术规范文档的语义消歧。
- **第二步**：从文档中提取特定航空实体与关系。
- **第三步**：构建领域知识图谱并进行逻辑挖掘。
### 复杂排程
- 供应链瓶颈分析 -> 生产算法匹配 -> 最终方案生成。

## 5. 落地技术栈
### 开发框架
- LangGraph (擅长处理循环与复杂状态)
- LangChain / AutoGen
### 模型对齐技术
- 通过 DPO/GRPO 优化特定节点的策略表现。
