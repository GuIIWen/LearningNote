- **AI Agent 核心知识体系**
  - **1. 架构与核心模块**
    - **B端 AI Agent**
      - **核心模块**: 意图识别、工具调用、多模态交互、权限控制(RBAC/ABAC/Guardrails)、任务流编排
      - **隐藏模块**: 可观测性与审计日志、长短期记忆
      - **优先级**: 意图识别 & 权限控制 > 工具调用 > 任务流编排 > 多模态交互
    - **框架选型 (手搓 vs 框架)**
      - **使用框架**: 生态对齐、标准化协议、现成集成库（适合POC验证/垂直领域）
      - **手搓开发**: 解决抽象泄露、调试地狱、Token消耗大（适合高并发/核心安全场景）
      - **混合模式**: 模块化手搓 (如 LiteLLM + Pydantic + 手搓核心决策逻辑)
    - **容错与高可用架构**
      - **Agent 卡死/超时容错**: 单机(重试/降级)、多智能体(心跳检测/冗余备份)
      - **降低高频调用延迟**: 本地缓存(语义缓存)、批量处理、预测执行(Speculative Execution)
      - **降级策略**: 优先保核心功能，可配置可恢复
      - **Checkpointing机制**: 定期存档与故障回滚 (全量状态快照，区别于预写日志WAL)
  - **2. 推理、规划与决策**
    - **复杂任务分解与推理**
      - **LLM增强推理**: 思维链 (CoT)、工具调用、反思机制、外部知识整合(RAG)
      - **链式推理**: 基于Prompt引导模型自主拆解任务
      - **外部规划器**: 引入专用规划工具(如PDDL/算法)更稳定
      - **规划Agent流程**: 目标拆解 -> 子任务排序 -> 执行监控 -> 异常处理
    - **因果推理提升决策**
      - **反事实分析**: 评估决策优劣，推演"如果不这样做"，增强可解释性
      - **因果图建模**: 识别混杂因素，剔除虚假统计相关性
      - **策略异质性 (CATE)**: 实现"千人千面"精准决策 (基于 S-Learner, T-Learner, X-Learner)
  - **3. 多智能体系统 (Multi-Agent)**
    - **Autogen 核心思想**
      - **核心**: 多智能体对话协作、可对话自定义、人机协作(Human-in-the-loop)、自动代码执行验证
      - **协作模式**: 双人对等博弈、群聊模式(动态指定发言)、分层嵌套模式
    - **通信、协同与环境**
      - **通信机制**: 显式通信 (发消息/协作强/成本高)、隐式通信 (环境动作观测/轻量)
      - **注意力机制 (GAT)**: 图注意力网络确定邻居节点通信权重，过滤冗余信息
      - **环境非平稳性挑战**: 应对其他Agent策略变化；方案：在线自适应、元学习、环境动态建模
      - **CTDE (集中训练分布式执行)**: 解决非平稳性与通信依赖，面临信息差距挑战
      - **联邦学习**: 隐私保护前提下的跨Agent协同模型训练与演进
  - **4. 强化学习 (RL) 与 演进**
    - **RL 与 LLM 的结合**
      - **高层规划+底层控制**: LLM负责认知与分解，RL负责精度物理控制
      - **LLM作为奖励函数 (RLAIF)**: 解决RL长链路任务的奖励稀疏问题
      - **RL作为LLM进化器**: 基于 PPO/DPO/GRPO 提升模型对齐与环境适应
    - **学习与探索机制**
      - **终身学习**: 弹性权重固化(EWC防遗忘)、模块化架构(局部更新)、经验记忆回放
      - **好奇心驱动**: 引入内在奖励 (基于预测误差) 解决稀疏奖励下的探索难题
      - **MPC(模型预测控制)与RL**: RL在线优化MPC参数、MPC作RL安全滤波器、残差学习降低学习难度
      - **Reward Hacking(奖励漏洞)**: AI投机取巧；解决：鲁棒奖励、多目标约束、人工审核、对抗训练
  - **5. 多模态与具身智能**
    - **多模态交互与意图**
      - **技术路线**: 后期分类融合、前期特征融合、原生多模态大模型(如 GPT-4o)
      - **一致性校验**: 跨模态语义对齐、逻辑冲突检测、多源投票仲裁（防御多模态越狱攻击核心）
    - **具身智能 (Embodied AI)**
      - **关键环节**: 多模态环境感知、长程任务规划分解、底层物理动作控制(直接输出扭矩等)
      - **学习机制**: 模仿学习(如Diffusion Policy解决冷启动)、强化学习(Sim-to-Real 仿真迁移现实)
  - **6. 安全、伦理与隐私**
    - **伦理对齐 (Alignment)**
      - **意识形态层**: 宪法AI (Constitutional AI) 静态底线约束与自我批判
      - **偏好反馈层**: DPO / GRPO 等相对奖励优化机制
      - **动作执行层**: 动态沙盒验证、敏感工具白名单管理
      - **逻辑透明层**: CoT 思维链实时审计与事后溯源
    - **决策安全与防护**
      - **应对危险指令**: 安全优先(直接拒绝)、伦理对齐(软约束)、权限分级最小化制衡
      - **多层防御体系**: 意图输入校验 -> 内部推理约束(护栏) -> 执行沙箱隔离 -> 行为审计反馈
      - **安全验证方法**: 形式化验证(逻辑数学绝对证明)、仿真极端测试、红队对抗攻击
    - **隐私数据处理**
      - **三大原则**: 数据最小化、权限角色最小化、处理目的限制
      - **技术路径**: 实时检测脱敏(替换或置换)、差分隐私(群体数据引入数学噪声)、边缘侧局部化处理
  - **7. 部署、工程化与未来趋势**
    - **架构部署优化**
      - **容器化进阶方案**: Agent编排逻辑与大模型推理(vLLM)分离、代码执行安全沙箱(gVisor)、持久化(K8s+Redis/Milvus)
      - **模型蒸馏 (Distillation)**: 大模型复杂逻辑向端侧小模型(SLMs)高保真迁移
      - **个性化适配**: 动态构建用户偏好画像与长短期记忆网络
    - **效能评估 (Evaluation)**
      - **核心指标**: 成功率、工具参数准确率、步骤效率与Token转化率、自我纠错率、异常鲁棒性
    - **Agent 未来发展突破**
      - **能量效率**: 模型架构稀疏化(MoE)、动态浅层推理(慢思考与提前退出)、软硬件协同优化
      - **交互范式演进**: Agent与APP混合演进 -> 终局：Agent-Native 原生无界面系统 (UI-less)
      - **核心能力跃迁**: 世界模型物理因果推演、群体协同涌现算法、全自动知识本体建模
      - **元宇宙应用**: 智能化身/NPC互动、自动化经济交易流转、AIGC实时场景生成
