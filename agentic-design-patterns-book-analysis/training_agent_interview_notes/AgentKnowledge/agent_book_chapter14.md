# Knowledge Retrieval (RAG) - 智能 Agent 设计模式

## 1. 核心理念：从“记忆”转向“查阅”
### 解决的核心痛点
- **知识滞后**：突破预训练模型无法感知实时/私有数据的限制。
- **事实幻觉 (Hallucination)**：通过强制模型参考外部事实，降低其自我发挥的概率。
### 架构本质
- **开卷考试模式**：先搜索相关资料，再总结并回答。

## 2. RAG 的三大技术支柱
### 向量嵌入 (Embeddings)
- **语义数学化**：将非结构化文本转化为高维向量，捕捉文本间的深层语义关系。
- **相似度计算**：利用余弦相似度等算法寻找向量空间中距离最近的片段。
### 文本分块 (Chunking)
- **粒度控制**：将长达数百页的波音手册拆解为原子化的 Chunks。
- **上下文保留**：在分块时保留部分重叠 (Overlap)，防止语义在断句处丢失。
### 向量数据库 (Vector Database)
- **高效存取**：专门针对大规模向量检索优化的存储引擎（如 Milvus, Weaviate）。

## 3. 工作流：R-A-G 三部曲
### 检索 (Retrieve)
- 用户提问 -> 转化为向量 -> 数据库检索 Top K 个最相关的文档块。
### 增强 (Augment)
- 将检索到的原始资料拼接到系统提示词中，为 LLM 提供背景支持。
### 生成 (Generate)
- LLM 在受限的上下文中进行推理，输出带有来源依据的答案。

## 4. 工业级进阶模式 (以航空制造为例)
### 知识图谱增强 (GraphRAG)
- **本体关系检索**：不仅仅找“相似片段”，更通过图数据库检索相关的实体节点（如：机翼 -> 紧固件 -> 材质属性），解决复杂跨领域推理。
### 混合检索 (Hybrid Search)
- **关键词 + 语义**：结合传统全文检索（BM25）与向量搜索，确保专业缩略语（如飞机型号、零件代码）的绝对匹配。
### 来源追溯 (Citations)
- 强制模型在输出时标明引用的文档编号和页码，满足航空工业的审计与安全性要求。

## 5. 框架实施建议
- **LangChain / LangGraph**：通过内置的 VectorStore 组件快速构建检索链。
- **性能优化**：针对本体建模场景，需在分块阶段注入领域词典，防止专业术语在嵌入过程中丢失特征。
