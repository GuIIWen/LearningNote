在统一的RLHF框架下，三种方法通过不同方式利用偏好信号优化策略模型，使其输出更符合人类期望

3. 特性对比总览
维度 PPO DPO GRPO
范式 基于奖励模型的强化学习 (on-policy RL) 直接偏好优化 (off-policy, 监督学习形式) 基于规则奖励的组相对强化学习 (on-policy RL)
是否需要奖励模型 (RM) 需要 (必须训练RM) 不需要 不需要 (使用规则/程序化奖励)
数据需求 大量偏好对 (训练RM) + 训练时在线采样 偏好对数据 (离线即可) 规则定义 + 在线采样
采样方式 每步都要采样 (on-policy) 无需采样 (仅计算log概率) 每步采样一组响应 (on-policy)
KL约束方式 显式KL惩罚 (在目标函数中) 隐式KL (通过log概率比实现) 显式/近似隐式KL (通过参考模型直接计算)
训练稳定性 较低 (对超参数敏感) 高 (非常稳定) 中等偏高 (比PPO稳定)
计算成本 高 (需RM推理 + 反复采样) 低 (仅前向计算log概率) 中等 (采样 + 规则奖励计算)
适用场景 通用对齐、复杂偏好/价值观对齐 (GPT-4等) 偏好对齐、人类反馈学习 (中小模型友好) 可验证任务、代码生成、数学推理等 (规则清晰)
4. 关键超参数对比
PPO
  • KL系数 β (控制KL惩罚强度)
  • PPO clipping ε (0.1~0.3)
  • 价值/奖励折扣因子 γ, λ (GAE参数)
  • Reward scaling / normalization (奖励归一化)
  • 训练epoch数 K (每个batch的更新轮数)
  • Mini-batch size
  • 学习率 LR, Weight Decay, Warmup Steps
  • 梯度裁剪 (Gradient Clipping)
  • 采样参数: 温度、Top-p、生成长度等
  • RM相关: RM batch size, reward offset等
DPO
  • KL系数 β (偏好强度, 常用 0.01~0.2)
  • 损失类型: sigmoid (标准) / JS / hinge 等
  • 偏好对采样策略: hard/easy pair比例
  • 参考模型选择 (SFT模型版本、是否早停等)
  • 学习率 LR, Weight Decay, Warmup Steps
  • 梯度裁剪
  • 批大小 (Batch Size)
  • 最大长度、温度等生成参数 (仅用于构造数据)
GRPO
  • KL系数 β (隐式/显式KL权重)
  • 规则奖励各项权重 (reward scale)
  • 组大小 G (每个prompt生成的响应数)
  • 优势归一化方式: 组内归一化/运行均值归一化
  • 学习率 LR, Weight Decay, Warmup Steps
  • 梯度裁剪
  • 采样参数: 温度、Top-p、生成长度
  • 规则设计相关阈值 (如正确性判定阈值等)
5. 优缺点总结

👍 优点

  • 表达能力最强，可学习复杂“隐式”偏好
  • 可处理稀疏/延迟奖励
  • 已被大规模模型实验验证(如ChatGPT)

👎 缺点

  • 训练复杂，超参数敏感
  • 需要训练和维护RM(成本高)
  • reward hacking风险
  • 训练不稳定，容易崩溃

👍 优点

  • 训练简单、稳定、高效
  • 无需奖励模型，成本低
  • 离线数据即可训练，易复现
  • 在多数通用对齐任务上表现良好

👎 缺点

  • 只能利用成对偏好信息，表达能力受限
  • 难以处理稀疏奖励或规则型任务
  • 对偏好数据质量较敏感

👍 优点

  • 无需RM，降低成本
  • 结合规则奖励，适合可验证任务
  • 比PPO更稳定，训练更容易
  • 在代码/数学等任务上表现突出

👎 缺点

  • 需要设计高质量的规则奖励
  • 规则不完善会影响效果
  • 泛化到开放性对齐任务时不如PPO
